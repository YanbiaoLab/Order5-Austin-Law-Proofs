## 载体与运算

载体 `T` 是全体有限树，构造子为常元 `e`、一元 `k` 和二元 `p`。没有正规性前提，没有树大小界，也没有对源等式添加条件。

引入二元命题 `R(a,b)`，表示构造所需的行像关系。它由以下四条规则归纳生成：

```text
direct: R(a, p(a,b))
back:   R(p(a,p(b,c)), c)
cross:  R(b,c) → R(p(a,b), p(b,c))
lift:   R(a,b) → R(p(a,b),c) → R(a, p(p(a,b),c))
```

乘法只有一个解码分支：

```text
op(a, p(x,t)) = x       当 R(x,t) 且 R(a,x)
op(a, b)     = p(a,b)   其他情形。
```

Lean 证书以经典可判定性解释这个条件，故 `op` 是合法的非可计算总函数；不需要证明某个外部程序的总性，也没有把 `R` 的正确性当作外部公理。`R` 是文件内定义的归纳命题，以下性质全部在 Lean 中证明。[Basic.lean](../proofs/Equation21866/Lean/Austin21866/Basic.lean)

## 原式为何成立

证明分为三个短步骤。

**第一，每次乘法的输出属于其左输入对应的行像关系：**

`R(a, op(a,b))`。

普通配对由 `direct` 保证；解码由分支条件直接保证。

**第二，任意连续两次左乘都能恢复原始右输入的关系：**

`R(op(y,op(z,x)), x)`。

逐一处理两次乘法的四种组合：普通/普通使用 `back`；解码/普通使用 `cross`；普通/解码直接使用解码条件；解码/解码使用 `lift`。这个分类解释了四条关系规则的来源。

**第三，若 `R(a,b)`，则仍存在 `c` 使**

`op(a,b)=p(a,c)` 且 `R(a,c)`。

这不是断言 `op(a,b)` 总是普通配对。`lift` 情形恰好会解码，但结果保留左子树 `a`，尾部换成关系见证 `c`。其余情形通过有限树构造子的无混淆性质排除错误解码。关键排除为 `¬R(a,a)`、`¬R(p(a,b),b)` 与 `¬R(p(a,p(b,p(c,d))),c)`。[Separation.lean](../proofs/Equation21866/Lean/Austin21866/Separation.lean)

现在令 `a=op(y,op(z,x))`、`u=op(x,w)`。第一步给出 `R(x,u)`；第三步给出

`op(x,u)=p(x,v)` 且 `R(x,v)`。

第二步给出 `R(a,x)`。于是最外层乘法正好触发解码：

`op(a,p(x,v))=x`。

这就是完整 E21866 原式。[Model.lean](../proofs/Equation21866/Lean/Austin21866/Model.lean) 中的主证明仅依赖上述已证定理，没有剩余分支或待证条件。

## 无限性和八题转移

取 `tower(0)=e`、`tower(n+1)=k(tower(n))`。树大小满足 `size(tower(n))=n`，因此 `tower` 是 Nat 单射。无限性不依赖有限范围枚举。

E21866 分别令 `z=y`、`w=y`、`w=z`，得到 E21714、E21864、E21865。四个对偶均使用 `dualOp(a,b)=op(b,a)`，并按库存公式的实际变量顺序独立核验。[Duals.lean](../proofs/Equation21866/Lean/Austin21866/Duals.lean)

## 本次构造的关键修正

此前的满射平方障碍正确地指出：不能保留“每个原子都没有平方原像”的旧设计；但不能因此排除所有有限树载体。本模型中平方会解码。例如 `h=e◇(e◇e)=p(e,p(e,e))`，而 `h◇h=e`。一般的平方满射性由原式对角代入得到。

另一条过强要求是“同一行的第二次左乘必须总是普通配对”。实际只需保持配对的左子树，并允许尾部发生变化。`lift` 同时完成连续解码情况下的左侧关系恢复和右侧形状保持，是本次补全成功的关键。

相比继续增加大量具体重写规则，四条归纳关系规则把一系列规则合并成有限的证明结构。它允许输出大于左输入，避免了不成立的左输入严格递减假设；定义乘法本身也不递归调用乘法。
