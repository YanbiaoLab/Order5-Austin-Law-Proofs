# E13992／E32280 Lean 形式化验收

22 个编译单元全部通过 Lean 4.33.1；包含 13 个穷尽根部与上下文重叠的证明、严格递减、汇合、规范形唯一性、两条原等式、Nat 单射及两份精确 Goal。

Python 只生成普通 Lean 证明文本，不作为正确性公理。所有变量重叠均在 Lean 中同步归约，未误用只适合左线性系统的关键对准则。

`norm` 通过经典选择取得已经证明存在且唯一的规范形。最终定理公理列表仅含标准的 `propext`、`Classical.choice`、`Quot.sound` 的子集。

本次分模块检查采样峰值 677.44 MiB，累计 9.172 秒。
单进程、单线程、`-M768`，每 0.2 秒监测 RSS，超过 1024 MiB 停止。
本批本地检查采用分模块编译，没有对合并文件提高内存限额进行本地编译。
本地最终证书导入经过检查的模块；远程提交包含这些模块的原文，远程状态见[独立验收记录](../aurora/README.md)。

复跑：`python3 scripts/check_13992_lean.py`。
完整源码哈希、命令和退出码见 [summary.json](summary.json)；核心公理列表见 [Audit.log](Audit.log)。
