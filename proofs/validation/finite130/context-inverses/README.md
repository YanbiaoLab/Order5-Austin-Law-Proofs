# 剩余有限侧问题：上下文逆映射与 Equation20911 的结构化简

## Equation20911 的五个结构定理

在有限模型中，源方程推出：

1. 所有左平移单射，因此双射。
2. 所有右平移单射，因此双射。
3. 所有平方相同，记共同值为 `c`。
4. `x ◇ c = x`，即共同平方是右单位元。
5. 令 `J(x) = c ◇ x`，则 `J²(x) ◇ J(x) = x` 且 `x ◇ J²(x) = J²(x)`。

这些定理只使用源方程和 `[Finite G]`；没有将消去律、右单位元或迭代关系作为额外公理加入。左消去律和两条迭代关系的 Prover9 线索已逐步重放为 Lean 等式证明；共同平方与右单位元直接在 Lean 中证明。五条定理的公理依赖只含 `propext`、`Classical.choice`、`Quot.sound`，最高采样 RSS 为 1255.59 MiB。源码哈希和日志见 [Equation20911-structure.json](Equation20911-structure.json)。

左右平移双射说明任何有限模型都是拟群（quasigroup）。结合共同平方，原方程可以写成 `c ◇ (((z ◇ x) ◇ x) ◇ z) = x`。使用此形式和标准左右除法规则的坍缩搜索未在 64 MiB 限制内完成。[搜索记录](quasigroup-summary.json) 的实际终止原因是内存上限，不能据此断言该化简路线不可能成功。

继续尝试了关系 `u ◇ v = v` 的传递性、沿 J² 的延伸，以及 J 是否保运算。[四项搜索](ascending-summary.json) 仅证明了上述迭代关系的第二条；其余项目在有界搜索中未获证明。不能把这些未获证明的性质用于后续 Lean 推导。
