# E12294 与 E33856：所有模型平凡

2026-09-15。设任意集合上的总运算满足

\[
\forall x,y,z,\quad x=y*(((z*y)*x)*(x*y)).
\]

则任意两元素相等。非空模型只能有一个元素；若允许空载体，则载体至多含一个元素。没有有限性、右消去律或预设幂等点假设。

[独立 Lean 证书](AllModelsTrivial.lean)直接陈述精确原方程推出 `∀ a b, a=b`。它只导入 Init，最终定理无公理依赖。[实际提交证书](Triviality.lean)保留完整证明并适配 Judge 的 `submission` 命名空间；[远端接受回执](judge_acceptance.json)绑定实际提交字节。

## 证明

以下所有乘积保留括号；不假设结合律。记 \(a^2=a*a\)，定义

\[
 P(a)=a^2*a,\qquad Q(a)=P(a)*a^2,\qquad
 D(a,u)=((u*a)*u)*(u*a).
\]

### 1. 左乘可逆与列像分离

原式给出 \(a*Q(a)=a\)，并使每个左乘映射满射。
它还给出 \(D(a,a*b)=b\)：令
\(c=(((a*b)*a)*(a*b))\)，先有 \(b*c=a\)；再在原式中取
\((x,y,z)=(b,c,b)\)，得到
\(b=c*((a*b)*a)=D(a,a*b)\)。故左乘也单射，而且
\(a*D(a,u)=u\)。

记 \(C(y,x,z)=((z*y)*x)*(x*y)\)。因为 \(y*C(y,x,z)=x\)，左消去给出：\(C(y,x,z)\) 与 \(z\) 无关。

有以下列像分离引理：

\[
\tag{F}
u*t=v*t\quad\text{且}\quad r*u=s*v\quad\Longrightarrow\quad u=v.
\]

证明：记共同右乘值为 \(k\)。由原式及左消去，
\(C(u,k,r)=t=C(v,k,s)\)。展开后，\(r*u=s*v\) 使两式的左因子相同；连续两次左消去即得 \(u=v\)。这里从未使用右消去律。

另外，从 \(a*q=a\) 可得

\[
\tag{B} q*P(a)=a,\qquad
(((z*q)*a)*a)=P(a),\qquad a*q^2=Q(q).
\]

第一式是原式取 \((a,q,a)\)；第二式比较原式取 \((a,q,z)\) 与第一式，再左消去 \(q\)；第三式比较 \(C(q,q,a)=C(q,q,q)\)。

### 2. 本轮关键推广：整个右列像的前驱唯一性

\[
\tag{U} ((z*a)*a)=P(a)\quad\Longrightarrow\quad z*a=a^2.
\]

这将此前针对规范项 \(Q(a)^2\) 的论证推广到任意右列像元素。为展示其证明不依赖候选标签，给出全部辅助项。

置 \(q=Q(a), b=a^2, p=P(a), m=z*a\)，并置

\[
t=p*m,\quad r=t*p,\quad v=r*q,\quad d=m*v,\quad
s=d*b,\quad u=r*s,\quad w=a*s.
\]

由假设 \(m*a=p\)、第 1 步和定义，依次得到：

| 等式 | 理由 |
|---|---|
| \(a*q=a,\ q*p=a,\ p*b=q\) | 自左除、(B)、定义 |
| \(a*r=m\) | \(a*D(a,m)=m\)，代入 \(m*a=p\) |
| \(v*a=b\) | 原式取 \((x,y,z)=(q,p,t)\)，再用 \(q*p=a,p*b=q\) 左消去 |
| \(q*d=r\) | 原式取 \((r,q,a)\) |
| \(a*s=v\) | 原式取 \((v,a,z)\) |
| \(b*u=d\) | 原式取 \((d,b,p)\) |
| \(m*w=d\) | \(a*s=v\) 及 \(d=m*v\) |
| \(u*(s*p)=w*(s*p)\) | \(C(p,s,t)=C(p,s,q)\) 及 \(q*p=a\) |

最后两行与 \(b*u=d\) 允许用 (F) 得 \(u=w\)。再把
\(r*s=a*s\) 和 \(a*r=z*a=m\) 代入 (F)，得到 \(r=a\)。于是
\(m=a*r=a^2\)，证明 (U)。

把 (B) 的二步前驱代入 (U)，立即得到

\[
\tag{C} a*q=a\quad\Longrightarrow\quad (z*q)*a=a^2
\qquad\text{对所有 }z.
\]

### 3. 从列像恒等式推出 \(P(Q(a))=a\)

固定任意 \(a\)，置 \(q=Q(a),h=Q(q),s=(h*a)*h\)。已有
\(a*q=a,q*h=q,a*q^2=h\)。

将 (C) 用于 \((a,q,z)=(q,h,h*a)\)，得到 \(s*q=q^2\)。
原式取 \((x,y,z)=(a,q^2,a)\)，利用 \(a*q^2=h\)，得到
\(q^2*s=a\)。由于同时有 \(a*q=a\)，元素 \(s,q\) 具有相同右乘 \(q\) 的值，且对应两列在 \(a\) 相交。(F) 给出 \(s=q\)，从而

\[
\tag{P} P(q)=q^2*q=a.
\]

### 4. 全部元素幂等，继而全模型平凡

由 \((a*q)*q=a=P(q)\)，对 \((q,a)\) 使用 (U)，得
\(a*q=q^2\)，故 \(q^2=a\)。

再由 \(D(q,q*q)=q\)、\(q*q=a\)、\(a*q=a\)，得到
\(P(a)=q=Q(a)\)。将该等式用于 \(q\)，结合 (P)，有
\(Q(q)=P(q)=a\)。桥接式 \(a*q^2=Q(q)\) 因此变成
\(a*a=a\)。这对所有 \(a\) 成立。

任取 \(a,b\)。由 \(b*b=b\) 和 (C)，有 \((a*b)*b=b=P(b)\)，再由 (U) 得
\(a*b=b^2=b\)。将这个右投影等式代入原式（取 \(x=a,y=b,z=b\)），右侧为 \(b\)，故 \(a=b\)。证毕。

## 对偶 E33856

E33856 为 `x = ((y ◇ x) ◇ (x ◇ (y ◇ z))) ◇ y`。定义 `a ⋆ b = b ◇ a`，E12294 的右侧在 ⋆ 下逐层展开，恰好得到 E33856 的右侧。因此满足 E33856 的任意运算，其相反运算满足 E12294，继而任意两元素相等。

[E33856 独立证书](../Equation33856/AllModelsTrivial.lean)嵌入全部基础证明，并以原题面的实际变量顺序验证转移。其 [Judge 证书](../Equation33856/Triviality.lean)已单独获得 [accepted / true](../Equation33856/judge_acceptance.json)。

## 研究反思

研究最初尝试构造无限部分运算，之后不断得到右列像、前驱与自左除的约束。突破来自检查规范前驱证明实际使用的最弱前提，将其推广到任意右列像元素，得到上面的 (U)。再把自左除点本身作为新的基点，便得到强制平凡性的闭合论证。

部分结构对已定义输入闭合，并不保证存在非平凡总延拓。最终结论是不存在非平凡模型；不能将这些证书计入无限模型证书或 Austin 律数量。
